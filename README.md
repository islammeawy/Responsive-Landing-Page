# Task Management App Landing Page

## Overview
This project is a sleek landing page for a fictional Task Management App targeting developers. The landing page is designed to effectively showcase the app's features, pricing plans, user testimonials, and provide easy navigation for potential users.

## Project Structure
The project consists of the following files:

- **index.html**: Contains the structure of the landing page, including sections for the header, hero, features, pricing, testimonials, and footer.
- **style.css**: Contains the styles for the landing page, defining layout, typography, colors, and other visual aspects to ensure a modern design.
- **images/**: 
  - **logo.png**: The logo for the Task Management App, used in the header section.
  - **profile.jpeg**: Image used for user avatars in the testimonials section.

## Features
- **Header**: Includes navigation links and the app logo.
- **Hero Section**: Features a headline, sub-headline, a call-to-action button, and an engaging image.
- **Features Section**: Highlights key features of the app with 3-4 cards.
- **Pricing Section**: Outlines three plans: Free, Pro, and Enterprise.
- **Testimonials Section**: Displays user quotes along with their avatars and company names.
- **Footer**: Contains links to privacy and terms, as well as social media links.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the landing page.
3. Customize the content and styles as needed to fit your branding and messaging.
